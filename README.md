About

I am a Data Science and Machine Learning practitioner focused on building reliable, interpretable, and business-oriented analytical solutions, with a growing specialization in banking, credit risk, and financial modeling.

My work combines Python, SQL, statistical analysis, machine learning, EDA, feature engineering, model validation, and risk analytics. I approach projects with an engineering mindset: understanding the business problem first, defining the correct population and observation framework, building reproducible pipelines, comparing models objectively, and translating model performance into business impact.

My primary area of interest is Credit Risk Data Science, including default prediction, PD/LGD/EAD concepts, application and behavioral scoring, vintage analysis, DEV/Test/OTT validation, model monitoring, and leakage-safe ML development.

I am also expanding into Generative AI and LLM engineering, including embeddings, vector search, retrieval-augmented generation, and AI applications for internal financial and analytical workflows.

Open To: Data Science · Machine Learning · Credit Risk Analytics · Risk Modeling · AI/ML Internships · Junior Data Science Roles

<details>
<summary><b>Home Equity Loan Default Prediction — Credit Risk ML</b></summary>
<br>

A complete machine learning project for predicting home equity loan default risk, designed around a real credit-risk modeling workflow.

Metric	Details
Stack	Python · Pandas · NumPy · Scikit-learn · Matplotlib · Seaborn
Scale	5,960 borrower records · mixed numerical/categorical features
Performance	Decision Tree ROC-AUC ≈ 0.868 · Random Forest train ROC-AUC ≈ 0.960
Security	Local analytical workflow · no sensitive production credentials
Impact	Identifies borrowers with elevated probability of default
Repository	View Repository

The project explores borrower characteristics such as loan amount, mortgage balance, property value, employment history, derogatory records, delinquency history, credit age, inquiries, credit lines, and debt-to-income ratio.

The workflow covers data quality analysis, EDA, missing-value treatment, categorical encoding, scaling, class imbalance, Logistic Regression, Decision Tree, Random Forest, confusion matrices, ROC-AUC evaluation, and overfitting analysis.

The project is structured around the principle that credit-risk models should be evaluated not only by overall accuracy, but by their ability to identify risky borrowers in an imbalanced portfolio.
